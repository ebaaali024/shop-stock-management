
# Zakat & Savings Tracker

## Project Overview
A mobile application that helps users track their assets, savings goals, zakat calculations, and zakat payments.

## Main Features
- User registration and login
- Manage assets and savings goals
- Calculate zakat based on recorded assets
- Record and track zakat payments
- Create, view, update, and delete records

## Technologies
- Flutter and Dart
- REST API backend
- Relational database
